# INC-016 — Cloudflare Meta egress

- **Estado:** contenido; alternativa operativa verificada.
- **Detectado:** 2026-09-24 UTC durante la validación de reconciliación aislada.
- **Componente:** `matrix24-reconciliation-staging` / Meta Graph API.
- **Canal y cuenta:** Instagram, `matrix24global`.
- **Alcance:** sólo lectura de un Media ID ya recibido. No afectó el publicador productivo ni Phase 2.

## Síntoma

El Worker de staging devolvió `502` con diagnóstico saneado `network/fetch` al consultar Meta. La clasificación manual de redirects confirmó que no se seguirían redirects con el encabezado Authorization.

## Impacto

El Worker de Cloudflare no podía ser fuente de verificación secundaria. El resultado no demostró ausencia de publicación, token inválido ni necesidad de reintento. La publicación Saudi-Houthi se mantuvo confirmada por su Media ID original.

## Evidencia

- Media ID exacto: `17901642846667497`.
- Cuenta exacta: `matrix24global`.
- Permalink confirmado: `https://www.instagram.com/p/Ddr0iCAjY1w/`.
- PR del reemplazo: #14, commit `62f5e0cba42738bf42851c56b960239c88924eea`.
- Ejecución manual verificada: GitHub Actions run `36082659224`.
- Resultado: `confirmed` sólo tras comparar Media ID y username exactos.

## Causa confirmada y límites

La causa confirmada es incapacidad del egress del Worker de staging para completar ese GET hacia Meta. No se determinó una causa de red más específica, y no se infiere que el fallo generalice a otros proveedores o entornos.

## Reparación aplicada

Se añadió un reconciliador manual de GitHub Actions con:

- Un único `GET` al Media ID suministrado.
- `contents: read`, dos minutos de timeout y ningún cron.
- El secreto `IG_READ_TOKEN` almacenado sólo como GitHub Actions secret.
- Salida `confirmed` únicamente para el ID y username exactos.
- Salida cerrada `unknown` ante error, identidad distinta o datos incompletos.

No publica, no reintenta, no modifica cola, no limpia claims, no habilita Phase 2 y no usa feeds vacíos como evidencia negativa.

## Validación

- Suite completa: 34 pruebas aprobadas el 2026-09-25.
- Workflow de CI de PR #14 aprobado.
- Run manual `36082659224` aprobado con evidencia exacta de ID, cuenta y permalink.

## Guardrails y recurrencia

Si un run devuelve `unknown`, preservar la historia en su estado existente y escalar; no ejecutar otro envío. Repetir el run sólo para un Media ID ya recibido de un recibo durable. La monitorización programada requeriría una lista durable de Media IDs confirmados y una revisión separada; no se habilita por este incidente.

## Rollback

Deshabilitar el workflow manual o eliminar el secreto detiene sólo las lecturas de GitHub Actions. No revierte publicaciones, receipts, claims ni estados de cola.
